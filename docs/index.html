Features

A home screen that looks like mission control.

Everything is built around one idea: your apps in orbit, with system telemetry always in view.

◎

Orbit dial

Eight favourite apps orbit a hub showing battery, with RAM and storage gauges on the ring. Drag around it to spin, and flick for momentum.

⬡

3D All Apps orbit

Tap the centre: every app on three rings. Drag to spin and tilt in 3D, swipe for pages, pinch to zoom.

✦

Neon icons

Every icon is redrawn as a glass orb with a glowing glyph in your accent colour, or as a colour orb. You can also keep the originals.

◉

Your profile

Your name, logo and a time-aware greeting right next to the clock.

⌘

IT Tools built in

Ten tools one tap away from home: network info, ping, DNS, port check, subnet calculator and more.

⚙

ALFA OS Settings

One tidy settings screen for profile, appearance, motion, home layout, updates and system.

2

Dual & work apps

Cloned apps (a second WhatsApp) and work-profile apps appear too, marked with a badge.

↻

Self-updating

ALFA checks GitHub Releases, downloads the new build and installs it. You just confirm.

◉

Six accents

Crimson, Ice blue, Mint, Amber, Violet or Mono. The whole OS, including icons, re-themes instantly.

IT Tools

Your pocket toolkit.

Grouped under one button on the home screen. Each tool runs in its own window, so it stays open in Recents while you switch apps.

01

Network info

Transport, interface, IPv4/IPv6, gateway, DNS, private DNS, MTU, signal, public IP.

02

Ping

ICMP echo to any host with live output; one-tap Google DNS, Cloudflare and gateway.

03

DNS lookup

A / AAAA records, reverse PTR and lookup timing.

04

Port check

TCP connect check on a single host you own or are authorised to test, with service names.

05

Subnet calc

Network, broadcast, mask, wildcard, host range, class and address type.

06

Device info

SoC, CPU, RAM, storage, display, battery health, kernel, security patch.

07

Hash / Base64

MD5, SHA-1, SHA-256, SHA-512, CRC32, Base64 encode and decode.

08

Password generator

Secure random passwords with an entropy estimate; tap to copy.

09

System panels

Jump straight to Wi-Fi, VPN, developer options, default apps, usage access and more.

10

App update

Check, download and install the latest ALFA build from GitHub.

Install

Up and running in a minute.

Download

Grab alfa-launcher.apk on your phone and allow your browser to install apps when Android asks.

Set as home

Open ALFA and tap Set as default. Pressing Home now brings you to ALFA instead of the stock launcher.

Make it yours

Tap ⚙ to add your name and logo, pick an accent and icon style, and arrange your orbit and dock.

Heads-up: because ALFA is installed from outside the Play Store, Google Play Protect may show a warning for an unrecognised app. ALFA is open source, so you can read every line on GitHub. Tap More details → Install anyway to continue.
